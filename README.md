## Personal Variant

- Theme: Underwater Research Base
- Motion: Pulse
- Interaction: Point-and-click
- Layout: Ring of six exhibits, radius 4 m
- Component prefix: x2322-

## Technology

- A-Frame 1.8.0
- HTML and JavaScript
- Visual Studio Code
- Live Server
- Google Chrome

## Run Locally

1. Open the project in Visual Studio Code.
2. Start Live Server from index.html.
3. Open the local URL in Google Chrome.
4. Use WASD to move and the mouse to look around.
